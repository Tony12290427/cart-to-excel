Privacy / 隐私说明

Updated / 更新日期：23 October 2026

Cart to Order Form helps HKUST Robotics Team members turn shopping-cart information into an order-form Excel file. Maintainer: Tony, tony20051229@gmail.com.

本工具帮助 HKUST Robotics Team 队员把购物车内容整理成订购表 Excel。维护者：Tony，联系邮箱见上方。

Your form / 你的表格

Cart text, product links, prices, quantities, competition name, student name and signature are processed in your browser. Export Excel saves the file locally. Save to Drive sends the completed workbook, including the signature, to Google Drive in the team's Order Form folder. People who have access to that folder can access the uploaded form according to its sharing settings.

购物车文字、商品链接、价格、数量、比赛名称、学生姓名和签名在浏览器中处理。本地导出会下载文件；选择上传时，完整表格（包括签名）会发送到 Google Drive 的团队 Order Form 文件夹，有相应共享权限的人可以访问。

Import from Google Drive reads only the workbook you explicitly select with Google Picker. Its items, amounts, currencies and form fields are processed in page memory. Update original sends the edited workbook back to the same file when you have editor access; Save a copy creates a new file. Google Sheets updates replace contents through Excel conversion and may not preserve Google-specific features. Import Excel reads a local file and does not upload it until you choose a Drive save action. Existing signatures are not reused; sign the edited form before saving.

从 Drive 导入只读取你在 Google Picker 明确选择的工作簿，在页面内存中处理商品、金额、币种和表格字段。有编辑权限时“更新原表”把编辑后的内容写回同一文件；“另存副本”创建新文件。原生 Google 表格更新经过 Excel 转换，Google 专属功能可能不保留。本机导入不会自动上传，只有选择 Drive 保存操作才发送。导入后需要重新签名，不沿用原签名。

Google access / Google 授权

The direct Drive integration requests drive.file: access to files created by this app or explicitly selected for this app, including the target folder. It reads selected file contents and versions, checks permissions, creates workbooks or updates the selected original, and reads file links and owner display names to show the result. The app does not request access to all of your Drive files in this mode.

新版直接上传与导入使用 drive.file 权限，只涉及工具创建或你明确选择给工具使用的文件及目标文件夹。工具读取文件/文件夹名称、内容、版本及权限，按你的操作创建表格或更新所选文件，并读取文件链接和所有者显示名称来展示结果。

During the transition, if direct upload has not been configured, Save to Drive uses the existing Google Apps Script deployment. That deployment requests broader Drive access and processes the workbook on Google's Apps Script servers before creating the file in the same team folder. Google shows the permissions for the active upload method before you grant access.

迁移期间，新版未启用时仍使用原有 Apps Script 上传。该方式申请较广的 Drive 权限，在 Google 的 Apps Script 服务中处理表格后存入同一团队文件夹。授权前请查看 Google 显示的实际权限。

Storage and removal / 保存与删除

The cart-to-Excel generator has no separate database of your forms or Google tokens. Direct-upload access tokens stay in page memory and are cleared on reload or when switching accounts; they are not saved in browser storage. Uploaded files remain in the team folder until removed by someone with the required permissions. You can revoke the app's Google access in Google Account connections. Revoking access does not delete files already uploaded; use Drive or contact the maintainer to request removal.

购物车导出工具没有单独保存表格或 Google 令牌的数据库。新版访问令牌仅存在当前页面内存中，刷新页面或切换账号时清除，不写入浏览器持久存储。已上传文件由 Drive 的共享权限和删除操作管理。撤销授权不会自动删除已上传文件，如需删除请在 Drive 操作或联系维护者。

Order management platform / 订单管理平台

The separate management platform reads the configured team Order Form folder with a backend service identity. It stores form links, project and student names, item descriptions, links, amounts and quantities, purchase and school-delivery confirmations, accepted quantities, issue notes, and the actor and time of each operation in its backend database and backups. It does not save signature images in that database. Approved team members can view the records; approved students can inspect received items, and managers can confirm purchases and school delivery.

独立订单管理平台通过后台服务身份读取指定团队 Order Form 文件夹，在后台数据库及备份中保存原表链接、项目和学生姓名、商品描述、链接、金额和数量、下单及到校确认、验收数量、异常备注、操作人和时间。平台数据库不保存签名图片。获准团队成员可以查看记录，学生登记验收，管理方确认下单和到校。

Platform Google sign-in verifies your Google account ID and display name on the server for membership and attribution. It does not request full-Drive access from signing-in students. Sessions use an expiring HttpOnly cookie. Membership can be disabled without removing historical audit records. Revoking Google access or deleting a Drive file does not automatically delete the platform's stored records or backups; contact the maintainer for removal and retention requests.

平台 Google 登录在服务端验证账号 ID 和显示姓名，用于成员身份及记录归属，不向登录的学生申请全盘 Drive 读取权限。登录会话使用有期限的 HttpOnly Cookie。停用成员不会删除历史操作记录。撤销 Google 授权或删除 Drive 文件不会自动删除平台已有记录与备份；删除及保留期限请求请联系维护者。

Service providers / 服务提供方

The website is hosted on Vercel and GitHub Pages. Its spreadsheet libraries, Google sign-in and folder picker load from their providers. These services may receive ordinary request information such as your IP address and browser details under their own privacy policies. The tool does not use Google user data for advertising, sell it, or share it with AI models. Its use of information received from Google APIs follows the Google API Services User Data Policy, including Limited Use requirements.

网站由 Vercel 和 GitHub Pages 托管，表格库和 Google 登录、文件选择器从各服务方加载。服务方可能根据其隐私政策处理 IP 地址、浏览器信息等请求数据。工具不将 Google 用户数据用于广告、出售或发送给 AI 模型，并遵守 Google API Services User Data Policy 的 Limited Use 要求。
